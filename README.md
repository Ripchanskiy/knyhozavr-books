# Книгозавр: книжки

Українські переклади книжок у суспільному надбанні. Готові файли EPUB і Markdown лежать у
[Releases](../../releases).

Переклад машинний (модель MamayLM), потім його вичитують люди: пропонують правки, валідатор їх схвалює, книжка
перезбирається. Вичитка йде в застосунку **Книгозавр**, а цей репозиторій зберігає готові випуски.

## Як завантажити

1. Відкрийте [Releases](../../releases).
2. Знайдіть книжку. Кожен випуск має тег `<книжка>-v<номер>`, наприклад `bambi-v3`. Більший номер означає новішу версію.
3. Завантажте файл:
   - `.epub` для читалки або телефона;
   - `.md` як текст, щоб порівняти версії чи цитувати.

В описі кожного випуску сказано, скільки правок увійшло з попередньої версії. Старі версії лишаються доступними.

## Які книжки тут бувають

Лише вільні від авторського права в Україні та ЄС: автор помер понад 70 років тому. Якщо книжку перекладаємо не
з мови оригіналу, те саме правило діє і для перекладача.

Оригінали здебільшого беремо зі [Standard Ebooks](https://standardebooks.org/ebooks).

## Якість

Це машинний переклад з людськими правками, а не літературний переклад. Можуть траплятися помилки, неоковирні
фрази й непослідовні імена. Знайшли помилку? Відкрийте [issue](../../issues): вкажіть книжку, версію і
процитуйте абзац.

## Ліцензія

Переклади: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/deed.uk). Можна вільно копіювати, змінювати
й поширювати без дозволу і без зазначення авторства (але згадка проєкту буде приємною).
Тексти оригіналів перебувають у суспільному надбанні.
